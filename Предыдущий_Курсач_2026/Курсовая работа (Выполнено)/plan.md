## ВВЕДЕНИЕ
*   **Актуальность:** Переход от классических сайтов к диалоговым интерфейсам (чат-ботам). Потребность выпускников в быстром поиске через удобные мобильные/веб-интерфейсы.
*   **Объект:** Программные комплексы интеллектуального поиска вакансий.
*   **Предмет:** Архитектура чат-бота, методы обработки естественного языка (NLP) и интеграция с векторными БД.
*   **Цель:** Разработать работоспособный чат-бот для семантического поиска вакансий, адаптированный под рынок Республики Беларусь.
*   **Задачи:** (Скорректированы под разработку ПО)
    1. Изучить теорию построения поисковых чат-ботов и RAG-систем.
    2. Проанализировать требования к интерфейсу и функционалу чат-бота.
    3. Спроектировать архитектуру приложения (FastAPI + Streamlit + PostgreSQL).
    4. Реализовать Backend-сервисы и API для взаимодействия с языковой моделью.
    5. Выполнить экспериментальную оценку качества работы чат-бота.
    6. Сформулировать пути развития продукта.

## ГЛАВА 1. ТЕОРЕТИЧЕСКИЕ ОСНОВЫ ПОСТРОЕНИЯ ИНТЕЛЛЕКТУАЛЬНЫХ ЧАТ-БОТОВ
1.1. Чат-боты как интерфейс взаимодействия в современных интеллектуальных системах.
1.2. Технологии семантического поиска и векторного представления текста.
1.3. Архитектура Retrieval-Augmented Generation (RAG) в задачах подбора персонала.
1.4. Метрики оценки эффективности диалоговых поисковых систем.

## ГЛАВА 2. АНАЛИЗ ПРЕДМЕТНОЙ ОБЛАСТИ И ПРОЕКТИРОВАНИЕ ПРИЛОЖЕНИЯ
2.1. Специфика поиска работы выпускниками ВУЗов Республики Беларусь.
2.2. Сравнительный анализ лексических фильтров и диалогового поиска.
2.3. Формирование технических требований к чат-боту (функционал, API, UI).
2.4. Обоснование выбора стека: FastAPI (Backend), Streamlit (Frontend), Groq (LLM).

## ГЛАВА 3. ПРОГРАММНАЯ РЕАЛИЗАЦИЯ И АРХИТЕКТУРА ЧАТ-БОТА
3.1. Трёхуровневая архитектура программного комплекса (Client-Server-DB).
3.2. Модель хранения данных: проектирование схемы БД в PostgreSQL с расширением pgvector.
3.3. Разработка Backend API на FastAPI: описание эндпоинтов и логики обработки запросов.
3.4. Реализация логики чат-бота: извлечение фильтров через LLM и векторизация запроса.
3.5. Алгоритмы гибкого поиска: релаксация фильтров и доменное ранжирование результатов.
3.6. Разработка пользовательского веб-интерфейса чат-бота на базе Streamlit.

## ГЛАВА 4. ЭКСПЕРИМЕНТАЛЬНАЯ ПРОВЕРКА РАБОТОСПОСОБНОСТИ СИСТЕМЫ
4.1. Методика функционального тестирования чат-бота на бенчмарках.
4.2. Анализ корректности интерпретации свободных запросов пользователя (LLM-валидация).
4.3. Количественная оценка качества поиска (метрик hit@1, hit@5).
4.4. Оценка производительности системы и времени отклика API.

## ГЛАВА 5. НАПРАВЛЕНИЯ ДАЛЬНЕЙШЕГО РАЗВИТИЯ ПРОЕКТА
5.1. Масштабирование системы: переход на микросервисную архитектуру и контейнеризацию (Docker).
5.2. Интеграция с популярными мессенджерами (Telegram, Viber) через Webhooks.
5.3. Реализация персонализации: учет профиля пользователя и истории поиска в чате.
5.4. Внедрение генеративного слоя для резюмирования вакансий (LLM-Summary).
