## Q29. Indeed — результаты исследования (только информация)

**Job Sync API** ([docs.indeed.com/job-sync-api](https://docs.indeed.com/job-sync-api/)) — GraphQL API для **ATS-партнёров**, которые **публикуют** вакансии **на** Indeed. Это write-side интеграция, не чтение. Требует партнёрского соглашения, OAuth через Partner Console, compliance с Indeed Apply. **Для агрегатора не подходит.**

**Publisher / Job Search API** (legacy XML/JSON feed, `indeed-js`, `indeed-php`) — раньше позволял искать вакансии по `q`, `l`, `userip`, `useragent`. **Deprecated / закрыт** (Job Search API — май 2021; Publisher XML feed — ~2023). Заменён widget'ом для embed, не для extraction.

**Publisher JavaScript Plugin** ([docs.indeed.com/indeed-plus/publisher-js-plugin](https://docs.indeed.com/indeed-plus/publisher-js-plugin/)) — iframe/widget для **отображения** вакансий Indeed на своём сайте. Данные **не отдаются** наружу для индексации.

**Вывод для проекта:** легального self-serve API для **чтения** вакансий с Indeed **нет**. Варианты:
1. HTML-коннектор с ограничениями (как LinkedIn) + фикстуры для тестов + сбор заранее.
2. Indeed остаётся **приоритетом 6** — первым режется при нехватке времени.
3. На защите честно описать ограничение в разделе «правовые аспекты».

## Q31. Зачем второй разметчик (справка)

Cohen's κ — коэффициент согласованности двух независимых разметчиков. Показывает комиссии, что оценки релевантности не субъективны. **Не обязателен** для курсовой; автор может разметить сам (слепая рандомизация порядка пар снижает bias). Если найдётся однокурсник на ~100 пар (~40 мин) — бонус к главе 4.
