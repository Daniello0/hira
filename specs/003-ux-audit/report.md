## 5. Вынесено на решение (меняет поведение или требует выбора)

1. **Реранкер на этом Mac неработоспособен**: TEI `bge-reranker-v2-m3` не отвечает за 150 с на топ-20, прогрев ~22 мин. Сейчас поиск через 8 с идёт без него. Варианты: ONNX-бэкенд, лёгкий реранкер из ADR-009, выключатель.
2. **Звонок до 3–5 с**: пропускать understand для коротких реплик звонка, более быстрая модель для understand, потоковый TTS. Все варианты меняют конвейер или модель.
3. Поиск целиком падает, когда эмбеддер TEI лежит (было 02.11, exit 137) — можно отвечать лексикой и графом.
4. Резюме не-PDF (DOCX, фото) кнопкой в профиль не добавить: API резюме принимает только PDF.
5. «Add as resume» живёт до перезагрузки вкладки (файл в памяти); после F5 — через Library.
6. Окно «Add Python to your profile?» всплывает после каждой полной загрузки страницы, пока не нажать Add/Dismiss, и перехватывает первый клик.
7. Из списка P: «New collection» показан на Free (P06), Downgrade без подтверждения (P26), «Use memory» сбрасывается в каждом чате (P33), оценки Relevant не сохраняются после F5 (P08), черновик Hira теряется при F5 (P18), нет смены пароля и удаления аккаунта (P38).
