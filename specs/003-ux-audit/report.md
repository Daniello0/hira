## 3. Что проверено (браузер на `localhost:3000`, стек в Docker)

- Регистрация по Enter → чат; перезагрузка — вход сохраняется (замечание №6 из «доработки.txt» не воспроизвелось).
- Гость: демо-чат отвечает (замечание №10 не воспроизвелось); выход → гость; вход → попадание в перенесённый гостевой чат.
- Тарифы: Upgrade до Pro применяется сразу, подпись в сайдбаре меняется без перезагрузки.
- Библиотека: New file по Enter, открытие, Delete → подтверждение по Enter; запароленный PDF → «The PDF could not be read…».
- Чат: вопрос о каталоге (294 вакансии, 2 удалённые) — верно; поиск Python — релевантные карточки с сайтом-источником; обрыв потока при перезапуске API → «Could not reload the chat», не вечное ожидание.
- Файлы: CSV + DOCX + PDF (чтение ~1 с), PNG (3,1 с через модель) + PDF; Hira пересказала все файлы, выделила навыки, предложила добавить резюме; «Add as resume» → список «Found in your resume» → Enter → навыки в профиле и в Context.
- Звонок: Start, микрофон в панели заблокирован → подсказка и «Type instead», Enter отправляет, ответ озвучивается (запросы synthesize 1,1–1,2 с), Hira опирается на резюме из библиотеки.
- Память: Hira сама записала 2 факта; Forget all → Enter.
- Избранное: Save на карточке → Favorites → двойной Remove — без ошибки.
- Cmd+K → «Python» → Enter открывает чат.
- Перевод: «Переведи на английский и сохрани как заметку…» → верный перевод + карточка «Draft from Hira» → Enter → «Saved to your library».
- Чат: Rename (Enter), Archive (уходит из списка, подсказка Restore), Restore, Delete → подтверждение по Enter → переход на /chat.
- Тарифы: Downgrade до Free — звонок показывает «Voice calls are part of the Pro plan»; Upgrade обратно.
- Профиль: заголовок → Enter → «Profile saved», после перезагрузки на месте; навыки из резюме в списке.
- Карточка вакансии: Explain match раскрывает факторы и ветки поиска; клик по названию открывает панель с описанием («навыки вакансии не извлечены» — ingestion не запущен).
- Оформление: Light/Dark переключаются сразу. Избранное: новая коллекция по Enter (Pro).
- Тесты: все изменённые тест-файлы (16 файлов, 121 тест) + тесты затронутых модулей; `tsc` web/core-api/llm-service/retrieval-service и `eslint` по изменённым файлам — чисто.

## 4. Не проверено и почему

- **Живой голос в браузере** — панель браузера блокирует микрофон. Распознавание и цикл звонка проверены через API на синтезированных фразах (`say`), черновые субтитры — юнит-тестами.
- **Скорость звонка 3–5 с не достигнута полностью**: 5,0–5,7 с до первого звука (+0,3–0,8 с хвост паузы VAD для голоса). Остаток — понимание запроса 1,4–2,5 с и первый токен ответа; ускорять дальше — менять конвейер/модели (п. 5).
- Не проходил: оценки Relevant, Copy/Read aloud, диктовку в чате (нужен микрофон), лимит 3 запросов гостя, две вкладки, мобильную раскладку — сценарии для них есть в scenarios.md.
- Ingestion-service не запускал — фоновое извлечение навыков тратит OpenRouter.
- Финальный полный прогон тестов не запускал (по вашим правилам — только по слову «финальный прогон»).

## 5. Вынесено на решение (меняет поведение или требует выбора)

1. **Реранкер на этом Mac неработоспособен**: TEI `bge-reranker-v2-m3` не отвечает за 150 с на топ-20, прогрев ~22 мин. Сейчас поиск через 8 с идёт без него. Варианты: ONNX-бэкенд, лёгкий реранкер из ADR-009, выключатель.
2. **Звонок до 3–5 с**: пропускать understand для коротких реплик звонка, более быстрая модель для understand, потоковый TTS. Все варианты меняют конвейер или модель.
3. Поиск целиком падает, когда эмбеддер TEI лежит (было 02.11, exit 137) — можно отвечать лексикой и графом.
4. Резюме не-PDF (DOCX, фото) кнопкой в профиль не добавить: API резюме принимает только PDF.
5. «Add as resume» живёт до перезагрузки вкладки (файл в памяти); после F5 — через Library.
6. Окно «Add Python to your profile?» всплывает после каждой полной загрузки страницы, пока не нажать Add/Dismiss, и перехватывает первый клик.
7. Из списка P: «New collection» показан на Free (P06), Downgrade без подтверждения (P26), «Use memory» сбрасывается в каждом чате (P33), оценки Relevant не сохраняются после F5 (P08), черновик Hira теряется при F5 (P18), нет смены пароля и удаления аккаунта (P38).
