# Референс ChatGPT: снятые значения

Снято 2026-10-31 с chatgpt.com (тема Dark, Accent Default, план Free). Окно 1244×930 и мобильная эмуляция 375×812. Источник: `getComputedStyle`, CSS-переменные страницы и `document.getAnimations()`.

ChatGPT меняется без предупреждения. Этот файл — снимок на дату, а не вечная правда. Значения — данные для `apps/web/src/styles/tokens.css`. В коде на файл не ссылаемся.

Пометки: **изм.** — измерено на элементе, **пер.** — значение CSS-переменной страницы, **оцен.** — оценка по скриншоту, перед использованием перемерить.

Скриншоты в `reference/`. Репозиторий публичный, поэтому имя аккаунта и названия чатов на них обрезаны.

## Анимации

| Токен | Значение | Откуда |
|---|---|---|
| Длительность basic / moderate / relaxed | 150 / 200 / 300 мс | пер. |
| `ease-basic` | `ease` | пер. |
| `ease-enter` | `cubic-bezier(.19, 1, .22, 1)` | пер. |
| `ease-enter-snappy` | `cubic-bezier(.23, 1, .32, 1)` | пер. |
| `ease-exit` | `cubic-bezier(.8, 0, .4, 1)` | пер. |
| `ease-in-out` | `cubic-bezier(.4, 0, .2, 1)` | пер. |

Что снято в работе:

- **Меню (открытие):** `opacity` 0→1 и `transform` к `scale(1)`, 150 мс, `ease` (`getAnimations`). Закрытие на замере анимации не вернуло, значит, выход мгновенный или короче шага опроса 10 мс.
- **Панель, выезд слева:** вход 250 мс `ease-enter`, выход 200 мс `ease-exit`, сдвиг на 1 и 0.5 шага сетки (`slide-from-left`, `slide-to-left`, CSS).
- **Сворачивание сайдбара:** широкая панель и рейл меняются через `opacity` за 150 мс.
- **Кнопки шапки:** `transition: opacity .15s, color .15s`.
- **Появление чипа:** `chip-enter`: `translate(-8px, 4px) scale(.92)` → лёгкий перелёт → покой.
- **Подсказка:** `tip-enter`: `translateY(1 шаг)` и `opacity`.
- **Загрузка:** текст с бегущим бликом (`loading-shimmer`, `background-position` от -100 % до 250 %), скелетоны с `pulse`.
- **Спиннер:** `spin`.
- **Reduced motion:** `:root[data-reduced-motion="true"]` отключает анимации.

Не снято: тайминг шторки и подложки на телефоне. Опрос через `requestAnimationFrame` ничего не вернул на этом экране. Для них берём «выезд слева» и подложку за 200 мс, а на стенде сверяем глазами.

## Структура экранов

**Сайдбар (развёрнут):** логотип, поиск, сворачивание → основные пункты → Projects → Recents со своим меню фильтра → внизу профиль с аватаром, именем и планом и кнопка Upgrade. Строка чата при наведении показывает `…` и Pin.

**Рейл:** логотип, New chat, Search, Chats, Library, внизу аватар.

**Шапка чата:** `…` (Chat actions), Upgrade, Share. На телефоне слева New chat и сайдбар.

**Главная (`/`):** приветствие и composer по центру. Меню `+` раскрывается под composer, на его ширину. В пунктах иконка, название и серая подпись в одну строку.

**Лента:** сообщение пользователя справа в пузыре, ответ без пузыря, под ним ряд действий. Над composer подпись `ChatGPT can make mistakes. Check important info.`

**Меню чата:** Rename, Pin, Plugins, View files in chat, Archive, Delete (красным).

**Меню профиля:** профиль, Upgrade plan, Personalization, Profile, Settings, Help, Log out.

**Настройки — отдельная страница, не модальное окно** (`/settings/<раздел>`): слева Back to app, поиск, разделы группами (Personal, Integrations), справа заголовок и карточки со строками. Appearance: Mode из трёх превью (System, Light, Dark), Theme, Accent, Background, Foreground, сворачиваемый Advanced.

**Viewport:** `width=device-width, initial-scale=1, viewport-fit=cover, interactive-widget=resizes-content`.
